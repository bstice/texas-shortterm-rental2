# PDF Guidebook File

## Location
Place the `guidebook.pdf` file in this directory (`/public/`).

## File Name
The file should be named `guidebook.pdf` to match the download path in the code.

## Access
- **Development**: `http://localhost:5173/guidebook.pdf`
- **Production**: `/guidebook.pdf`

## Download
The PDF will be automatically downloadable via the "Download PDF" button in the website header.

## Updating
To update the PDF:
1. Replace the `guidebook.pdf` file in this directory
2. The new file will be available immediately (no build needed for public files)
3. Users will download the updated version on their next download

## Notes
- File size should be reasonable (< 10MB recommended)
- File should be optimized for both screen viewing and printing
- Ensure the PDF contains all essential guidebook information
